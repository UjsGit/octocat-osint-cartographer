# 🗺️ OsintoCat

**OSINT Cartographer Octocat — GitHub Octocat Drawing Contest Entry**

The character tracks scattered clues using maps, coordinates, route lines, pins, and investigative tools to transform fragmented information into meaningful connections.

## Design Goals

- Original Octocat variant
- Cartography + OSINT inspired identity
- Strong mascot readability
- Clean silhouette
- Minimal background
- Contest-ready illustration

## Visual Elements

- Folded investigation map
- Magnifying lens
- Cartography kit
- Route connections and evidence pins
- Field research outfit
